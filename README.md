# Audio-Files

The Pony Driland audio files repository.

## About

This repository is responsible for storing audio files that will be used in animation projects and similar media, being entirely dedicated to the **Pony Driland** project.

## Usage

This repository is meant to be used as a **submodule**, or it should be placed in the same folder as the animation project (which is the recommended approach).

Example of the recommended folder structure:

```
root/
├── Audio-Files/
└── Episode-1/
```

This way, the animation project can reference the audio files through a relative path such as `../Audio-Files`, keeping both repositories independent while still working together.
